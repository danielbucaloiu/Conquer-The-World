# Conquer the World

# Español

## De que trata 
Juego de estrategia para navegador, pixel art, **HTML + CSS + JavaScript vanilla**. El jugador elige uno de **196 países** sobre un mapa mundial con geometría real y conquista el mundo invadiendo vecinos (por tierra o por mar).

## Uso de IA
El juego esta enteramente hecho con IA (vibecodeado). Este juego esta creado simplemente por puro entretenimiento sin ningún otro motivo alguno. No empoderes la capacidad de la IA; empodera la capacidad humana 

# English

## What it is about

A browser-based strategy game featuring pixel art, built with **HTML + CSS + vanilla JavaScript**. The player chooses one of **196 countries** on a world map with real geometry and conquers the world by invading neighbors (by land or sea).

## Use of AI

The game is entirely made with AI (vibe coded). This game was created simply for pure entertainment with no other motive whatsoever. Do not empower the capability of AI; empower human capability.
